## Роль

Эксперт по компьютерному зрению и Python-разработчик.

## Задача

Написать программу на Python для бинаризации изображения с графическим интерфейсом.  
В реализации должны использоваться:

- `tkinter` для интерфейса
- `PIL` (`Pillow`) для загрузки и отображения изображений
- `numpy` для быстрой обработки пикселей
- `matplotlib` для визуализации гистограммы яркости

## Требования к функционалу

### 1. Загрузка изображения

- Пользователь должен иметь возможность выбрать файл через диалоговое окно.
- После загрузки изображение должно автоматически переводиться в оттенки серого для дальнейшей бинаризации.

### 2. Ручной режим бинаризации

- В интерфейсе должен быть слайдер с диапазоном значений от `0` до `255`.
- При перемещении слайдера порог `t` должен меняться в реальном времени.
- Результат бинаризации должен пересчитываться и отображаться сразу, без дополнительных кнопок.

### 3. Автоматический режим

- Должна быть кнопка `"Найти порог"`.
- При нажатии программа должна вычислять оптимальный порог `t` по методу Оцу.
- Для вычислений нужно использовать формулы из лекции:

  - вероятность появления яркости:
    `P(i) = n_i / N`
  - накопленная вероятность для первого класса:
    `q_1(t) = sum(P(i))`
  - средняя яркость первого класса:
    `mu_1(t)`
  - межгрупповая дисперсия:
    `sigma_b^2(t) = q_1(t) * (1 - q_1(t)) * (mu_1(t) - mu_2(t))^2`

- После вычисления найденный порог должен:
  - устанавливаться в слайдер
  - отображаться в интерфейсе
  - сразу применяться к изображению

### 4. Оптимизация

- Нельзя использовать медленные поэлементные циклы вроде `getpixel` для основной обработки.
- Все операции бинаризации и расчета гистограммы должны выполняться через `numpy`.

## Требования к интерфейсу

### 1. Общий макет

- Окно должно быть разделено на две части.
- Слева размещаются изображения:
  - исходное изображение
  - обработанное бинаризованное изображение
- Справа размещаются:
  - панель управления
  - динамический график гистограммы

### 2. Панель управления

Панель управления должна содержать:

- кнопку загрузки изображения
- слайдер ручного выбора порога
- текстовое отображение текущего значения порога
- кнопку автоматического поиска порога методом Оцу

### 3. Отображение изображений

- Исходное и бинаризованное изображения должны быть показаны рядом.
- Изображения должны масштабироваться для удобного просмотра в окне приложения.

## Визуализация гистограммы

- Необходимо использовать `matplotlib` для построения гистограммы яркости изображения.
- Ось `X` должна отображать яркости в диапазоне `0-255`.
- Ось `Y` должна отображать количество пикселей `N`.
- Гистограмма должна обновляться после загрузки нового изображения.

## Интерактивность графика

- На гистограмме должна отображаться вертикальная линия, соответствующая текущему порогу `t`.
- При перемещении ручного слайдера линия должна двигаться в реальном времени.
- При автоматическом поиске порога линия также должна перестраиваться на найденное значение.

## Ожидаемый результат

Итоговая программа должна позволять:

- загружать изображение
- вручную подбирать порог бинаризации
- автоматически находить порог методом Оцу
- видеть исходное и обработанное изображение одновременно
- анализировать распределение яркости по гистограмме
- наблюдать текущее положение порога на графике в реальном времени
